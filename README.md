# KnightsAI Video Studio

MVP de renderização de vídeo vertical com Remotion e GitHub Actions.

## Como renderizar

1. Abra **Actions** no GitHub.
2. Selecione **Render KnightsAI Demo**.
3. Clique em **Run workflow**, escolha `main` e confirme.
4. Quando a execução terminar, abra o job e baixe o artefato `knightsai-demo-video`.
5. Extraia o ZIP para obter o MP4.

A primeira versão gera um vídeo animado de 10 segundos sem áudio. Narração e cenas serão integradas em uma próxima etapa.
